# 별과 우주 기억 퀴즈

빌드와 설치가 필요 없는 정적 HTML/CSS/JavaScript입니다. `dist` 안의 파일 5개를 같은 폴더 그대로 웹 호스팅에 업로드하세요. 외부 라이브러리와 서버 API가 없습니다.

20장 카드, 21문항. 처음부터 숨기며 오답 시 0.9초 후 전체 선택을 초기화합니다. 같은 문제의 카드 위치는 유지합니다. 정답 후 다음 문제에서 재배치합니다.

오늘의 기록은 기기 현지 날짜 기준이며 완료 문제 ID를 localStorage에 저장합니다. 중복 정답은 하루 1회 집계합니다. 저장소를 지우거나 다른 브라우저/주소를 쓰면 기록은 공유되지 않습니다. 저장 차단 시 화면에 안내하고 현재 세션에서 계속합니다. 학생이 로컬 데이터를 변경하는 것을 보안상 차단하지는 못합니다.

가로 태블릿용 기본 화면은 5열 4행입니다. 작은 세로 화면과 확대 사용 시 스크롤을 허용하며 기록 창은 내부 스크롤을 사용합니다.

테스트: `node --test tests/core.test.cjs`

## 풀이 시간 기록

상단 누적 시간은 오늘 첫 문제 표시부터 마지막 정답까지 계속 측정합니다. 다음 문제 대기, 탭 전환, 페이지를 닫았다 다시 여는 시간도 포함됩니다. 날짜가 바뀌면 새로운 하루의 기록을 시작합니다.

문제별 시간은 해당 문제 표시부터 정답까지이며, 각 도전의 첫 완료 시간을 저장합니다. 새로고침하면 미완료 문제와 시작 시각을 이어갑니다. 21문제 완료 후 누적 시간은 멈추며 복습해도 최초 기록은 유지됩니다. 오늘의 기록에서 문제별 풀이 시간과 전체 완료 시간을 확인할 수 있습니다. 기존 완료 기록은 보존하지만 예전의 소요 시간은 추정하지 않습니다.

시간 계산 테스트: `node --test star-memory/tests/*.test.cjs` (프로젝트 루트 기준).
브라우저 통합 검증: Playwright가 설치된 모듈 경로를 `PLAYWRIGHT_MODULE` 환경 변수로 지정하고 `node star-memory/tests/browser-timing.cjs`를 실행합니다. Windows Edge를 사용하며 별도 로컬 테스트 서버와 임시 브라우저 프로필을 만듭니다.

문제를 다 읽은 뒤 `Ready!` 버튼을 누르면 카드 위치 힌트가 한 번 공개됩니다. 자동으로 힌트를 시작하지 않으며, 읽고 준비하는 시간도 풀이 시간에 포함됩니다.

페이지를 열면 아케이드 인트로 화면이 나타납니다. `Game Start`를 누르면 첫 문제가 표시되고 새 게임의 시간 측정을 시작합니다. Game Start는 기존 기록을 보관하고 항상 새 도전의 첫 문제 표시 시각부터 0초로 시작합니다. 이전 도전을 계속하려면 인트로의 별도 이어하기 버튼을 선택합니다.

`↻ 다시 도전`은 확인 후 현재 진행·점수·풀이 시간을 초기화하고 21문제를 새로 시작합니다. 최고 점수는 유지하며, 기존 완료 문제와 문제별 시간 및 완료/중단 시점의 누적 시간은 오늘의 기록 → 이전 도전 기록에 보관됩니다. 보관에 실패하면 초기화하지 않습니다.

21문제를 모두 완료하면 ALL CLEAR 화면에서 총 시간과 등급을 표시합니다. 추정 게임 기준은 S 7분 이내, A 7분 초과~10분 이내, B 10분 초과~14분 이내, C 14분 초과~18분 이내, D 18분 초과입니다. 중3 대상의 읽기·암기·입력·대기를 고려한 임시 기준이며 실제 학생 표본을 측정한 교육 평가 기준은 아닙니다. S는 문항당 평균 20초, A는 약 29초, B는 40초, C는 약 51초에 해당합니다. 이전 기록에 문제별 시간이 빠져 있으면 등급을 추정하지 않습니다.

## 아케이드 아이템

정답을 맞히면 50% 확률로 아이템 1개를 획득합니다(전체 보기/한 글자/오답 지우기 균등 확률). 총 3칸이며 중복 보관할 수 있습니다. 가득 차면 추가 지급하지 않고, 마지막 문제와 복습에는 지급하지 않습니다. 같은 문제에서 재접속해 중복 지급받지 않습니다.

Ready 힌트 종료 후 풀이 중 사용합니다. 전체 보기는 모든 남은 카드를 2초 공개하고, 한 글자는 다음 정답 카드 1장을 2초 공개합니다. 공개 중에는 다른 선택을 잠시 막습니다. 오답 지우기는 정답에 쓰이지 않는 카드 최대 3장을 이번 문제에서 제외합니다. 풀이 시간은 계속 흐릅니다. 보관함과 사용 횟수는 도전별로 저장되며 완료 화면·오늘의 기록·이전 도전 기록에 사용 횟수를 표시합니다. 새 도전은 빈 보관함으로 시작합니다.

브라우저 아이템 검증: `node star-memory/tests/browser-items.cjs` (기존과 동일한 PLAYWRIGHT_MODULE 설정).
