# 풀이 시간 구현 계획

목표: 콤보 HUD를 누적 시간으로 교체하고 문제별 시간 및 전체 완료 시간을 오늘의 기록에 표시한다.
설계: 최초 문제 표시 시각과 마지막 정답 시각의 차이를 사용한다. 다음 문제 대기, 탭 전환, 새로고침 및 닫았다 다시 여는 시간도 포함한다. 문제별로는 문제 표시부터 정답까지 측정한다. 날짜별 별도 localStorage 키로 기존 완료 ID 기록을 보존한다. 첫 완료 시간만 보관하고 복습은 덮어쓰지 않는다. 과거 기록의 시간은 추정하지 않는다.

- [x] core.js: 시간 정규화, 시작/완료, 누적 시간, 표시 함수. 양쪽 파일에 적용. 순수 함수 테스트로 대기 포함/재개/중복/잘못된 저장값/완료 후 정지 검증.
- [x] app.js: 초기화, 다음 문제, 정답 저장, 날짜 전환 및 storage 이벤트에 연동. 진행 중 문제는 재접속 시 우선 재개.
- [x] index.html/styles.css: 시간 HUD, 문제별 시간, 총 시간 및 측정 기준 안내.
- [x] node --test 전체 테스트 및 JS 구문 검사. 실제 DOM 통합 테스트로 저장/새로고침/기록 표시 검증.

검토 초점: 예전 완료 기록, 저장 실패, 자정, 복습, 새로고침. Git 저장소가 아니므로 커밋 없이 현재 파일을 수정한다.

검증: 순수 함수 및 기존 테스트 10개 통과. Windows Edge에서 루트와 dist 각각 21문제 정답, 대기 시간 포함, 새로고침 재개, 복습 시 기록 유지, 전체 완료 후 정지, 기록 표시, 다른 탭의 storage 갱신, 자정의 정답 화면 대기, 예전 기록 보존 검증 통과. 독립 리뷰의 두 문제(다른 탭 시작 시각 덮어쓰기, 정답 화면 자정 측정 시작)를 수정하고 브라우저 검증했다.
