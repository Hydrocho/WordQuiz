# 별과 우주 기억 퀴즈

사용자가 확정한 구성: 빌드 없는 HTML/JS, 가로형 태블릿, 처음부터 숨긴 20장 카드, 정답 순서로 선택, 오답 시 전체 선택 초기화, 무작위 21문제, localStorage 오늘 기록.

5열 4행 카드와 오른쪽 문제를 배치한다. 오답은 900ms 공개 후 모두 뒤집으며 위치는 유지한다. 정답 후 다음 문제 버튼으로 진행한다. 하루 완료 문제는 중복 없이 집계한다. 모든 문제 완료 후 복습 가능하다. 기록 모달만 내부 스크롤을 허용한다. 저장 실패를 표시하고 메모리에서 계속 진행한다. 날짜는 기기의 현지 날짜를 사용한다.

서버 저장과 내부 저장 중 사용자가 내부 저장을 선택했다. 조작 방지를 보장하지 않으며 별도 점수 대신 유효한 완료 문제 ID 목록에서 집계한다.
